# Validation
Ten phyloSMC CTest suites pass in static Debug, shared Release and address/undefined-behaviour builds. Curupixa’s 44 suites also pass, including Autotools. The suites include analytic engine checks, the compiled C API example, and CLI analyses covering unrooted and rooted modes, online addition, joint DNA models and multiprocessing. Tests use explicitly seeded streams and retain assertions in Release builds.
The original rooted-prior tests remain explicit rooted analyses. New tests separately integrate the two-tip binary likelihood under the unrooted single-edge prior and the rooted two-edge prior. Their different analytic evidence values detect accidental placement of two exponential priors on one unrooted edge. Online updates are checked against analytic three-tip evidence, including the split-length factor.
Unknown observations leave the prior unchanged. Tests check actual-edge means, unrooted quartet probabilities, fixed root splits and the moments of inferred parameter priors after rejuvenation. Curupixa separately checks normalised GTR against HKY at matching exchangeabilities, detailed balance, and conditional tree-prior sampling and probabilities.
Complete serial and multiprocessing populations are compared, including weights, parameters and clock ages/rates. The CLI is also exercised with several processes. These checks establish reproducibility on the tested build; they do not promise identical arithmetic across platforms.
Static/shared builds, address/undefined-behaviour checks and installed C/C++ headers are checked during development. Build logs and generated fixtures stay under `build/` and are not distributed as production sources. A test suite establishes small-problem numerical contracts; posterior exploration and performance on a particular dataset require independent analyses and representative benchmarks.
