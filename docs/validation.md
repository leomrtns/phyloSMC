# Validation
The initial implementation passes five CTest suites in strict C17 static and shared builds and under AddressSanitizer/UndefinedBehaviourSanitizer. Leak detection is disabled because of the tracing environment. Tests cover the engine, a compiled C API example, and command-line annealed, online and relaxed-clock analyses. A Python ctypes smoke test and an installed CMake client also call the shared library successfully.
The scientific engine tests integrate the two-tip binary likelihood analytically under independent exponential branch priors and compare it with the estimated evidence. An informative two-to-three-tip online update has a separate analytic evidence calculation, including the alternative topologies. Unknown observations leave the prior unchanged; tests check mean branch lengths and the four-tip PDA balanced-tree probability after rejuvenation and online weighting. These checks detect omission of the online split-length factor and incorrect log-scale MH ratios.
All four clock families run with topology, age and rate proposals, and their output can be converted to substitution-length trees. Identical initial streams reproduce entire runs. Invalid random callbacks and unsupported clocked online updates return errors with no result. Curupixa separately checks clock densities against direct formulas, sampled arithmetic means, dated-tip consistency, weight calculations and temperature selection.
These tests establish small-problem numerical contracts. They do not establish large-data speed, adequate mixing on difficult posteriors, or equivalence to another phylogenetic inference package. Run independent analyses and inspect weighted topology/parameter summaries; resampling ESS alone does not diagnose exploration. All development builds and test fixtures remain under `build/`.
