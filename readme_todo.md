# Development decisions and further work
This file records implementation choices and future work for the maintainers. User-facing statistical assumptions and limitations remain in the README and tutorial.
## Implemented in this revision
Unrooted inference is the non-clock default, using a singleton-anchored computational orientation with exactly one exponential prior per actual edge. Rooted PDA remains an explicit movable-root mode. Fixed root splits can be supplied or selected by midpoint rooting of neighbour joining. Curupixa samples the conditional topology directly, including ranked dated priors.
Joint Bayesian inference covers F81/HKY/GTR DNA parameters, the non-clock branch-prior rate, applicable clock dispersion, coalescent scale and birth/death rates. Mean clock rate remains fixed unless its inference is explicitly selected. Prior settings are exposed rather than silently estimated from the same data. The API preserves convenient fixed-model use for general alphabets.
The POSIX backend distributes particle work across processes. For reproducibility across worker counts, serial and process execution normalise the tree representation through the same ordered Newick form. Fork/transport overhead is material; the backend supplies a correctness reference before further performance work.
## Performance and exploration
Incremental likelihood updates need dependency tracking, proposal rollback and per-worker reusable partials. This is separate from process-level scheduling. A persistent process pool and compact node-preserving tree transport could reduce stage overhead. Benchmark these changes on representative alignments, rather than inferring speed from core count.
Online placement remains uniform over eligible edges, with explicit importance corrections. Guided proposals and an annealed arrival bridge would address severe weight concentration. Additional topology proposals and topology-specific diagnostics could improve exploration. Surviving initial ancestors should not be presented as the number of distinct posterior topologies.
## Model extensions
Across-site mixtures, codon processes and empirical protein matrices need Curupixa model support before CLI integration. Serial-tip priors, calibrations and clocked online insertion need explicit sampling measures and density corrections. Fixed origin age remains an input under the birth–death prior.
Other allowed sets of trees should be implemented through reusable Curupixa samplers paired with probability evaluators. Root-split conditioning is the current supported restriction. Arbitrary supplied trees are not automatically hard constraints, and a restricted initial population must not be called an unrestricted prior sample without proposal corrections.
Library dependency boundaries in Curupixa remain a separate discussion. No MPI implementation is planned in this revision.
